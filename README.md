**Keyboard-first navigation for Firefox, designed primarily for people with disabilities and users who have difficulty using a mouse.**

OneKey Navigator allows users to control essential browser functions using the keyboard, reducing the need for mouse interaction.

## Why OneKey Navigator?

Standard browser navigation often requires precise mouse movements, clicking small interface elements, and repeated hand movements.

OneKey Navigator provides an alternative: essential browser operations can be performed using simple keyboard shortcuts.

The extension was created with accessibility in mind, especially for people with limited mobility or difficulty using a mouse.

## Features

- Switch between browser tabs
- Close the current tab
- Open a new tab
- Open a private window
- Navigate backward and forward
- Restore a recently closed tab
- Duplicate the current tab
- Move tabs left and right
- Pin and unpin tabs
- Reload the current page
- Stop page loading
- Open a new browser window
- Close the current window
- Navigate through links and interactive elements using the keyboard
- Open the selected link
- Open the selected link in a new tab
- Keyboard-first navigation without requiring a mouse

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `F1` | Close current tab |
| `F2` | Next tab |
| `F4` | Previous tab |
| `F7` | New private window |
| `F8` | New tab |
| `F9` | Back |
| `F10` | Forward |
| `Ctrl + .` | Toggle link navigation |
| `Enter` | Open selected link |
| `Shift + Enter` | Open selected link in a new tab |

Additional functions can be assigned through the extension's settings.

## Link Navigation

Press:

`Ctrl + .`

to enable link navigation.

Use the arrow keys to move between available links and interactive elements.

Press:

`Enter`

to open the selected element.

Press:

`Shift + Enter`

to open the selected link in a new tab.

This allows users to navigate many websites without reaching for the mouse.

### Installation

#### For regular users

**Option 1 — Mozilla Add-ons**

Install OneKey Navigator directly from the Mozilla Add-ons platform.

**Option 2 — ready-made `.xpi`**

Download the signed `.xpi` file from the **Releases** section on GitHub and open it in Firefox. After verifying the Mozilla signature, Firefox will offer to install the extension.

The source code can be loaded through `about:debugging` → **This Firefox** → **Load Temporary Add-on** → `manifest.json`.
